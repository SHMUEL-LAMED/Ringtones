# ראש בראש — מצעד המוזיקה הגדול

אתר התוכנית "ראש בראש": התוכנית האחרונה בדף הבית, ארכיון מלא של כל התוכניות עם האזנה
ישירה באתר, ואזור אישי לכל מאזין. באתר יש תוכניות בלבד — בלי רשימות שירים וזמרים (אלה באתר הסקר).

האתר סטטי (GitHub Pages), בעברית מימין לשמאל, ובנוי על מערכת העיצוב "אולפן לילה":
רקע חצות עם זוהר נע וגרעיניות עדינה, זהב חם, טיפוגרפיה ענקית (Karantina) וגוף ברור (Heebo),
כרטיסי זכוכית כהים, עטיפה צבעונית שנגזרת מהעונה ומהמזהה של כל תוכנית, תקליט שמסתובב
בזמן ניגון, אקולייזר חי בגיבור, סרט נע של התוכניות, מספרים רצים, גילוי בגלילה, מעבר רך
בין דפים (View Transitions) ואור שעוקב אחרי הסמן. כל התנועה כבויה תחת
`prefers-reduced-motion`.

## מה יש באתר

| דף | מה יש בו |
| --- | --- |
| `index.html` | הגיבור עם המדליון, התוכנית המומלצת/האחרונה עם נגן, "מאיפה שעצרתם", תוכניות אחרונות, מספרים, הצטרפות לתפוצה ו"כתבו לנו" |
| `archive.html` | כל התוכניות: חיפוש, סינון לפי עונה / עם הקלטה / לאחר כך, מיון, תצוגת רשת / רשימה / לפי עונות |
| `episode.html?ep=…` | דף תוכנית: הקלטה, תיאור, קישור לכל רגע (`&t=שניות`), הורדה, שיתוף, תגובה למגישים, קודמת/הבאה, עוד מאותה תקופה |
| `me.html` | האזור האישי (ראו למטה) |
| `updates.html` | דף העדכונים שמנהל כותב באזור הניהול |
| `admin.html` | אזור הניהול (ראו למטה) |

### הנגן הקבוע

נגן אחד לכל האתר, שנשאר פתוח במעבר בין דפים. **ההקלטות מנוגנות בנגן של האתר** — גם
כשהקובץ שמור בדרייב. אין הפניה החוצה, אין iframe, ושום דבר מהממשק של ספק האחסון לא מוצג
לציבור; קישורי הדרייב שבנתונים מוסתרים מהדפים הציבוריים (`RoshUI.publicLinks`).

איך זה עובד: גוגל מגיש קובץ דרייב משותף כאודיו רגיל (Range, CORS) לשרתים, אבל עונה 403 לכל
בקשת דפדפן חוצת־אתרים (`Sec-Fetch-Site: cross-site`) — כך שאי אפשר לטעון אותו ישירות ב־`<audio>`
מאתר אחר. לכן `RoshUI.streamCandidates(ep)` מחזיר כתובות לפי עדיפות:

1. `{apiBase}/api/program/stream/{מזהה}` — ה־Worker של אתר הסקר מזרים את הקובץ ומעביר Range
   (הקוד ב־`worker/program-api.ts` במאגר `rosh-berosh`).
2. הכתובת הישירה (`drive.usercontent.google.com/download?…`) — גיבוי לדפדפנים שאינם שולחים
   את הכותרת, וגם כתובת ההורדה (`RoshUI.downloadUrl`; ניווט/הורדה לא נחסמים).

הנגן עובר אוטומטית למקור הבא כשמקור נכשל, ואם כולם נכשלו מציע "ניסיון חוזר" והורדה.
כל תוכנית מקבלת שדה מחושב `ep.stream` (הכתובת הראשונה; לא נכנס ל־JSON שמתפרסם).

- תקליט מסתובב ואקולייזר חי בזמן ניגון (`body.is-playing`)

- פס התקדמות עם ריחוף שמציג את הזמן; שם התוכנית גם על מסך הנעילה (Media Session)
- ממשיך מאיפה שעצרתם (נשמר במכשיר), עם אפשרות "מההתחלה"
- מהירות 0.75×–2×, טיימר כיבוי, השתקה, שיתוף הרגע הנוכחי
- קיצורי מקלדת: רווח ניגון/השהיה, חצים ±15 שניות, Shift+חץ לתוכנית הבאה/הקודמת, 0–9 קפיצה לאחוז, M השתקה, +/− מהירות, R תוכנית אקראית, `?` לעזרה
- "הפתיעו אותי" — תוכנית אקראית עם הקלטה

## האזור האישי

`me.html` — כל אחד מתחבר עם Google ישירות מהדף (כפתור Google; האישור נשלח ל־`/api/program/auth/google`) ורואה:
ממשיכים מאיפה שעצרתם, "לאחר כך", היסטוריית האזנה, שעות האזנה והעדפות (מהירות קבועה).
הנתונים האישיים נשמרים במכשיר (localStorage). בכותרת האתר מופיע תמיד קישור לאזור האישי
(עם השם כשמחוברים).

**כפתור "ניהול" מוצג רק למי שמחובר בחשבון שמוגדר כמנהל באתר הסקר** (`user.isAdmin`) — בכותרת
ובאזור האישי ("מעבר לניהול"). מי שמחובר ואינו מנהל רואה את האזור האישי בלבד; `admin.html`
נשאר נעול לו. הסשן (`rosh:cf:session`) נשמר לכל משתמש; `isAdmin` מתרענן מול `/api/program/me`.

> ההתחברות של מאזינים שאינם מנהלים וההזרמה דרך ה־Worker דורשות את גרסת ה־Worker שמנפיקה
> סשן לכל חשבון Google (`isAdmin:false` למי שאינו מנהל) וכוללת את `/api/program/stream` —
> ראו את ה־PR המקביל במאגר `rosh-berosh`. עד שהוא נפרס: הכניסה פתוחה למנהלים בלבד, והנגן
> נופל לכתובת הישירה ומציע הורדה.

## אזור הניהול

`admin.html` — ארבעה חלקים, בשפה פשוטה, בלי קודים ובלי מזהים. כל שינוי נשמר מיד (במכשיר
וגם **בטיוטה משותפת** בשרת, כך שאפשר להתחיל במחשב ולהמשיך בטלפון). "פרסום לאתר" מעביר את
הטיוטה לכולם; עד אז רק המנהלים רואים אותה. בכניסה הראשונה נפתח מדריך קצר (וכפתור `?` תמיד זמין).

1. **תוכניות** — רשימה עם חיפוש וסינון, וטופס לכל תוכנית: שם, תאריך, מספר, עונה, אורחים,
   תיאור, הקלטה (העלאה או קישור; האורך נקרא מהקובץ), תמונה (העלאה, קישור, או **יצירת תמונה
   אוטומטית** בסגנון האתר משם התוכנית והתיאור), מוצגת/מוסתרת, מומלצת בדף הבית, **פרסום מתוזמן**
   (התוכנית עולה לאתר במועד שנקבע), טקסט מוכן לוואטסאפ, שכפול, מחיקה עם ביטול, **גרסאות קודמות**
   של התוכנית, ותצוגה מקדימה של הכרטיס. **בחירה מרובה**: הצגה, הסתרה, שיוך לעונה ומחיקה של כמה
   תוכניות יחד.
2. **האתר** — **הודעה בראש כל הדפים** (עם קישור ותאריך סיום), **דף עדכונים** (`updates.html`,
   מופיע בתפריט כשיש עדכונים) ועונות לסידור הארכיון.
3. **מאזינים** — **סטטיסטיקות האזנה** אנונימיות (האזנות, מאזינים, שעות, גרף ימים, התוכניות
   הכי נשמעות, טלפון/מחשב), **הודעות מהמאזינים** (מ"כתבו לנו" בדף הבית ובדפי התוכניות) ומספר
   הנרשמים לרשימת התפוצה.
4. **פרסום** — מה השתנה, **בדיקת תקינות** (מה חסר, **כפילויות**, **בדיקת ההקלטות**, **בדיקת
   תמונות וקישורים**), כפתור הפרסום, **גרסאות קודמות** (כל פרסום נשמר אוטומטית; שחזור בלחיצה)
   וכלים מתקדמים: **קישור לתצוגה מקדימה** של הטיוטה, קובץ גיבוי ושחזור ממנו, העברת ההקלטות
   מהדרייב לאתר, **ניהול המנהלים** (אותה רשימה של אתר הסקר) והחשבון.

הכניסה לניהול ולאזור האישי היא **ישירות עם Google מתוך האתר** (כפתור Google בדף עצמו, בלי דף
ביניים). הקישור "כניסה דרך אתר הסקר" נשאר כגיבוי. כדי שהכפתור יעבוד, כתובת האתר
(`https://shmuel-lamed.github.io`) צריכה להופיע ב־Authorized JavaScript origins של ה־OAuth client
בגוגל.

**רשימת התפוצה** — בדף הבית ובאזור האישי: מתחברים עם Google וההצטרפות היא בלחיצה אחת. הכתובת
נלקחת מהחשבון המחובר ונשמרת באותה רשימה של אתר הסקר (`subscribers`), שמנוהלת שם.

### סנכרון עם ניהול אתר הסקר

- **כניסה אחת** — כפתור "לניהול הסקר" מעביר לניהול אתר הסקר בלי כניסה נוספת (קוד מעבר חד־פעמי,
  `POST /api/program/handoff`), ובניהול הסקר יש לשונית **אתר התוכניות** שמציגה את הניהול הזה
  בפנים (`admin.html?handoff=…&embed=1`). התנתקות במקום אחד מנתקת משניהם.
- **הודעה משותפת** — בהודעה שבחלק "האתר" מסמנים איפה להציג: באתר התוכניות, באתר הסקר או בשניהם.
- **"הצביעו עכשיו"** — כשההצבעה במצעד פתוחה (`settings.survey.open` בקטלוג), פס בראש כל הדפים.
- **תוכנית מקושרת למצעד** — שדה `surveyId`; דף התוכנית מציג קישור להצבעה כשהמצעד הזה פתוח.
- **מנהלים וגיבוי** — אותה רשימת מנהלים (עם כניסה אחרונה), וגיבוי אחד לשני האתרים בניהול הסקר,
  לשונית "ארכיון וגיבויים".

### מקור הנתונים

`data/site.json` → `storage.provider` קובע מאיפה האתר קורא:

**`"cloudflare"` (מוגדר כרגע)** — התוכניות נשמרות באותו Cloudflare D1 של אתר הסקר,
והקלטות ותמונות חדשות נשמרות באותו R2. הציבור קורא רק תוכניות מוצגות; כתיבה אפשרית רק
למנהלים שכבר מוגדרים באזור **הרשאות** של אתר הסקר.

**מי שמנהל את אתר הסקר מנהל גם כאן.** באזור הניהול נכנסים עם כפתור Google שבדף עצמו ומקבלים
סשן ל־30 יום; אותה רשימת מנהלים מכריעה. הקישור "כניסה דרך אתר הסקר" פותח את חלון הכניסה הישן
(`/api/program/login`) למי שכבר מחובר שם. הוספה או הסרה של מנהל מתבצעת רק בלשונית **הרשאות** של אתר הסקר
ומשפיעה מיד גם על אתר התוכניות — אין רשימת מנהלים נפרדת, וגם סשן קיים נבדק מול הרשימה
בכל בקשה.

- כתובת ה־API מוגדרת ב־`data/site.json` תחת `storage.cloudflare.apiBase`.
- הטבלאות `program_episodes` ו־`program_settings` נוצרות אוטומטית ב־D1 של אתר הסקר.
- אם Cloudflare אינו זמין, האתר נופל חזרה ל־`data/episodes.json` לקריאה בלבד.

**`"json"`** — בלי שרת בכלל. האתר קורא את `data/episodes.json` מהמאגר, ו"פרסום" באזור הניהול
מוריד קובץ מעודכן שמעלים למאגר.

### מבנה תוכנית (`data/episodes.json`)

```json
{
  "id": "2026-09-19",
  "slug": "2026-09-19",
  "number": 38,
  "season": "2026",
  "title": "שירי הסתיו",
  "date": "2026-09-19",
  "description": "מה היה בתוכנית…",
  "cover": "https://…/cover.jpg",
  "audio": "https://…/episode.mp3",
  "duration": 3480,
  "tags": ["מצעד"],
  "guests": [],
  "featured": true,
  "visible": true,
  "publishAt": "",
  "links": [{ "label": "הפלייליסט", "url": "https://…" }]
}
```

`publishAt` (לא חובה, `"2026-10-01T20:00"`) הוא מועד פרסום מתוזמן. `seasons` הוא מערך של `{ id, title, year, note }`.
שדה `tracks` ישן נשמר אם קיים, אבל האתר לא מציג אותו.

## הרצה מקומית ובדיקה

```bash
node tests/catalog.cjs         # הקטלוג, כתובות ההזרמה, הסתרת קישורי האחסון, העלאות
npx http-server -p 4180 .      # בחלון אחד
node tests/browser-smoke.mjs   # בחלון שני (דורש Playwright: npm i -g playwright; OFFLINE=1 מדלג על ההזרמה)
node tests/admin-smoke.mjs     # אזור הניהול, הפרסום והאתר אחריו — מול Worker מדומה
```

הבדיקה עוברת בדפדפן אמיתי על הקטלוג האמיתי: הנגן נפתח ומזרים את ההקלטה ישירות (כולל קפיצה
באמצע), המיקום נשמר במעבר לארכיון, סינון וחיפוש, דף תוכנית בלי נגן חיצוני, האזור האישי,
וכפתור הניהול שמופיע רק לסשן של מנהל.
