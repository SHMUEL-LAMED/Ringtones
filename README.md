# ראש בראש — מצעד המוזיקה הגדול

אתר התוכנית "ראש בראש": התוכנית האחרונה בדף הבית, ארכיון מלא של כל התוכניות,
ורשימת השירים של כל תוכנית — כשכל שיר מקושר לרגע שבו הושמע בהקלטה.

האתר סטטי (GitHub Pages), בעברית מימין לשמאל, ובנוי על מערכת העיצוב של ראש בראש:
קרם חם, כרטיסים לבנים, זהב אחד וכחול־כהה אחד.

## מה יש באתר

| דף | מה יש בו |
| --- | --- |
| `index.html` | הגיבור עם המדליון, התוכנית המומלצת/האחרונה עם נגן ורשימת שירים, "מאיפה שעצרתם", תוכניות אחרונות, מספרים |
| `archive.html` | כל התוכניות: חיפוש (גם בשירים ובזמרים), סינון לפי עונה / עם הקלטה / לאחר כך, מיון, תצוגת רשת / רשימה / לפי עונות. חיפוש שיר מחזיר **את הרגע** שבו הושמע בכל תוכנית |
| `episode.html?ep=…` | דף תוכנית: הקלטה, תיאור, רשימת השירים עם קפיצה לרגע, קישור לכל רגע (`&t=שניות`), שיתוף, קודמת/הבאה |
| `admin.html` | אזור הניהול (ראו למטה) |

### הנגן הקבוע

נגן אחד לכל האתר, שנשאר פתוח במעבר בין דפים:

- פס התקדמות **מחולק לשירים** לפי רשימת השירים; ריחוף מציג את שם השיר בכל נקודה
- "מתנגן עכשיו" מתעדכן לפי הזמן, וגם על מסך הנעילה (Media Session)
- ממשיך מאיפה שעצרתם (נשמר במכשיר), עם אפשרות "מההתחלה"
- מהירות 0.75×–2×, טיימר כיבוי (בזמן או בסוף השיר), השתקה, שיתוף הרגע הנוכחי
- קיצורי מקלדת: רווח ניגון/השהיה, חצים ±15 שניות, Shift+חץ לשיר הבא/הקודם, 0–9 קפיצה לאחוז, M השתקה, +/− מהירות, `?` לעזרה

## אזור הניהול

`admin.html` — עובדים על **טיוטה** שנשמרת בדפדפן (Ctrl+S). האתר במכשיר הזה מציג את הטיוטה,
כך שאפשר לבדוק הכול לפני שמפרסמים. "פרסום" מעביר את הטיוטה למקור.

- יצירה, שכפול, מחיקה (עם ביטול), הסתרה/הצגה, סימון "תוכנית מומלצת"
- כל השדות: כותרת, מספר, תאריך, עונה, כתובת (slug אוטומטי), תיאור, תגיות, אורחים, תמונה, הקלטה, אורך (נקרא מהקובץ), קישורים
- **עורך רשימת השירים**: נגן תצוגה מקדימה, כפתור "סמן" שמעתיק את הזמן מהנגן לשיר, "+ שיר מהנקודה בנגן",
  גרירה לסידור, מיון לפי זמן, ו**הדבקת רשימה** שלמה (שורה לשיר, עם או בלי זמנים)
- ניהול עונות, עריכת JSON מלאה עם אימות, ייבוא וייצוא קובץ
- תצוגה מקדימה חיה של הכרטיס

### מקור הנתונים

`data/site.json` → `storage.provider` קובע מאיפה האתר קורא:

**`"cloudflare"` (מוגדר כרגע)** — התוכניות נשמרות באותו Cloudflare D1 של אתר הסקר,
והקלטות ותמונות חדשות נשמרות באותו R2. הציבור קורא רק תוכניות מוצגות; כתיבה אפשרית רק
למנהלים שכבר מוגדרים באזור **הרשאות** של אתר הסקר.

באזור הניהול לוחצים **חיבור עם Google**. חלון ההתחברות נפתח בכתובת המאושרת של אתר הסקר,
ומחזיר לאתר התוכניות סשן מנהל מאובטח ל־30 יום. הוספה או הסרה של מנהל מתבצעת רק באתר
הסקר ומשפיעה מיד גם על אתר התוכניות — אין רשימת מנהלים נפרדת.

- כתובת ה־API מוגדרת ב־`data/site.json` תחת `storage.cloudflare.apiBase`.
- הטבלאות `program_episodes` ו־`program_settings` נוצרות אוטומטית ב־D1 של אתר הסקר.
- אם Cloudflare אינו זמין, האתר נופל חזרה ל־`data/episodes.json` לקריאה בלבד.

**`"json"`** — בלי שרת בכלל. האתר קורא את `data/episodes.json` מהמאגר, ו"פרסום" באזור הניהול
מוריד קובץ מעודכן שמעלים למאגר.

### מבנה תוכנית (`data/episodes.json`)

```json
{
  "id": "2026-09-19",
  "slug": "2026-09-19",
  "number": 38,
  "season": "2026",
  "title": "שירי הסתיו",
  "date": "2026-09-19",
  "description": "מה היה בתוכנית…",
  "cover": "https://…/cover.jpg",
  "audio": "https://…/episode.mp3",
  "duration": 3480,
  "tags": ["מצעד"],
  "guests": [],
  "featured": true,
  "visible": true,
  "tracks": [
    { "at": 0, "title": "פתיחה", "artist": "", "note": "" },
    { "at": 185, "title": "שם השיר", "artist": "שם הזמר", "note": "" }
  ],
  "links": [{ "label": "הפלייליסט", "url": "https://…" }]
}
```

`at` הוא זמן בשניות מתחילת ההקלטה. `seasons` הוא מערך של `{ id, title, year, note }`.

## מבנה הקוד

```
index.html, archive.html, episode.html, admin.html
assets/css/rosh.css      מערכת העיצוב (טוקנים, כרטיסים, נגן, ארכיון)
assets/css/admin.css     פריסת אזור הניהול
assets/js/ui.js          כותרת, פוטר, הודעות, עיצוב זמנים ותאריכים
assets/js/store.js       שכבת הנתונים: JSON / Cloudflare / טיוטה מקומית, חיפוש, מיקומי האזנה
assets/js/player.js      הנגן הקבוע
assets/js/home.js, archive.js, episode.js, admin.js
assets/img/medallion.svg המדליון (מתוך מערכת העיצוב)
assets/audio/demo.wav    הקלטת דוגמה של 42 שניות לתוכניות הדוגמה
data/site.json           שם, תיאור, קישורים, מקור הנתונים
data/episodes.json       התוכניות (מקור כש-provider="json", וגיבוי אחרת)
supabase/schema.sql      סכמה ישנה שנשמרה רק לתיעוד המעבר
sw.js, manifest.webmanifest   התקנה כאפליקציה ועבודה בלי רשת (המעטפת בלבד; ההקלטות לא נשמרות)
tests/browser-smoke.mjs  בדיקת דפדפן אמיתי
```

אין תהליך בנייה ואין תלויות. עורכים קובץ, מרעננים.

## הרצה מקומית ובדיקה

```bash
npx http-server -p 4180 .      # בחלון אחד
node tests/browser-smoke.mjs   # בחלון שני (דורש Playwright: npm i -g playwright)
```

הבדיקה עוברת בדפדפן אמיתי על מה שקשה לראות בקוד: הנגן נפתח ומתנגן, לחיצה על שיר קופצת
לרגע הנכון, המיקום נשמר במעבר לארכיון, סינון וחיפוש שירים, קישור עמוק לרגע, יצירת תוכנית
באזור הניהול עם הדבקת רשימת שירים, ושהטיוטה מופיעה באתר.
