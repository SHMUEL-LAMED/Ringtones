# צלצולים

אתר ליצירת צלצולים מתוך קובצי שמע: העלאת שיר, בחירת קטע,
עריכה והורדה כקובץ WAV.

## התקנה כאפליקציה ועבודה בלי אינטרנט

האתר הוא אפליקציית ווב מותקנת (PWA) — אפשר להוסיף אותו למסך הבית או להתקין
אותו מהדפדפן, והוא נפתח בחלון משלו. חיתוך צלצול הוא ממילא עבודה של Web Audio
בתוך הדף, ולכן Service Worker (`sw.js`) שומר את הדף ואת `profile.js` ומגיש
אותם גם בלי רשת. שתי היכולות שכן דורשות חיבור הן ההתחברות לפרופיל והפרדת
השירה ב־AI, שמושכת את מנוע ההסקה שלה מ־CDN בזמן אמת.

## הפרופיל

לאתר יש פרופיל משותף עם [אתר התווים](https://shmuel-lamed.github.io/SongToNotes/):
אותה התחברות עם Google, אותו שם תצוגה ואותה היסטוריה. שני האתרים מוגשים
מאותו מקור, ולכן מי שהתחבר באחד מהם כבר מחובר גם בשני.

כל צלצול שיורד נשמר אוטומטית בפרופיל (טבלת `ringtones` ב־Supabase) ומופיע
בשני האתרים מכל מכשיר. צלצולים שנוצרו לפני ההתחברות נשמרים במכשיר בלבד,
ועולים לפרופיל בפעם הראשונה שנפתחת ההיסטוריה אחרי התחברות.

בלי חשבון האתר עובד בדיוק כמו קודם: אפשר ליצור ולהוריד צלצולים, וההיסטוריה
נשמרת במכשיר בלבד. גם אם ספריית Supabase אינה נטענת, עורך הצלצולים ממשיך
לעבוד במלואו.

הקוד נמצא ב־`profile.js`. הגדרות הצד השרתי — הטבלאות ומדיניות ה־RLS —
נמצאות ב־`supabase/schema.sql` שבמאגר SongToNotes. כדי שההתחברות תחזיר את
המשתמש לדף הזה יש להוסיף את
`https://shmuel-lamed.github.io/Ringtones/` לרשימת כתובות ההפניה המורשות
בהגדרות ה־Authentication של הפרויקט ב־Supabase.

## הרצה מקומית

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

בפריסה יש להגדיר את `OPENAI_API_KEY` כסוד בסביבת השרת. אין להעלות קובצי סביבה ל-GitHub.
