# צלצולים ויוצר השירים

אתר ליצירת צלצולים וליצירת שיר מקורי. OpenAI יוצר מילים ותכנון מוזיקלי,
והדפדפן מלחין ומייצא ליווי אינסטרומנטלי מקורי כקובץ WAV.

## הרצה מקומית

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

בפריסה יש להגדיר את `OPENAI_API_KEY` כסוד בסביבת השרת. אין להעלות קובצי סביבה ל-GitHub.
